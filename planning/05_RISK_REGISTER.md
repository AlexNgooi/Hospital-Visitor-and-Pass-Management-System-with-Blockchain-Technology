# 当前风险与处理

更新：2026-11-10。当前交付/外部未决事项见 [10](10_BASELINE_REVIEW.md)。

| 风险 | 处理与验收 |
|---|---|
| 源码已改但仍运行旧版 | 核对 checkout/分支、JAR/前端构建版本及用户启动目录；不自动重启旧进程 |
| 误用或覆盖旧数据库 | 固定专用 demo schema/account；测试随机前缀库与独立账号；不自动认领旧库或执行 repair/clean |
| 初始化/恢复中断 | MySQL DDL不承诺整体回滚；保留数据、日志、密钥与完整备份，先核对失败阶段 |
| 私有密钥丢失 | 持久化并与数据库一起备份；现有库缺匹配 keys 时拒绝生成替代值 |
| QR/复制链接过期或外传 | 短有效期、server校验、明确复制即时使用、不记录完整链接；不把扫码当在场证明 |
| 多标签身份/旧数据混淆 | 同 profile 共享登录/退出；保留counter授权及版本检查；新标签入口保留原页面，不静默重放写命令 |
| 多 pass 并发重复借出 | authority/root/sorted-card锁、库存活动唯一约束、原子批次、逐张归还和幂等 |
| MOCK 被误认为医院核验 | 明确 SYNTHETIC 来源、人工核实；真实资料/API/政策需批准 |
| 无期限或遗失被算为已归还 | due_at/returned_at/closed_at语义独立；统计区分登记与pass、实际归还与遗失 |
| 外部网络/低gas/未知链提交 | 本机业务不等待链；outbox/对账/eventId去重；只在授权启用后验证 |
| Testnet 清空或公开数据 | 链仅保存非敏感 commitment，MySQL保留原始业务/证据；Testnet不保证持久性 |
| 执行了未隔离的SQL测试 | 测试默认不连接数据库，显式 opt-in；受限账号，只创建/删除自己精确随机库 |
| 历史 PASS 被当成当前验收 | 保留当时版本/方法，不伪改成native已通过；当前未执行项明确 NOT_RUN |
